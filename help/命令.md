# LPT v2 命令

当前主分支是 v2-only。旧 v1 入口实现已归档；当前 `main.py / main-pretrain.py / main-sft.py / main-LoRA.py` 是 v2 主线入口。

PowerShell 运行时建议固定使用 `-NoProfile`，避免 `$PROFILE` 中的主题输出污染日志：

```powershell
pwsh -NoProfile -Command "python -m compileall lpt_config lpt_model lpt_runtime lpt_data lpt_protocol lpt_training lpt_workflows lpt_eval tests tools"
```

## v2 训练 smoke

```powershell
python tools/train_lpt_v2_smoke.py --profile lpt_v2_assist --preset lpt_v2_dev_tiny --vocab-size 128 --batch-size 1 --seq-len 16 --steps 1 --lr 1e-4 --device auto --dtype auto --save-checkpoint artifacts/lpt_v2/smoke/model.pt
```

参数：

- `--profile`：`lpt_v2_bootstrap | lpt_v2_sdpa_local | lpt_v2_paged_kv | lpt_v2_assist | lpt_v2_base | lpt_v2_memory`。
- `--preset`：`lpt_v2_dev_tiny | lpt_v2_small | lpt_v2_base | lpt_v2_large`。
- `--device`：`auto | cpu | cuda:0` 等 PyTorch 设备名。
- `--dtype`：`auto | fp32 | fp16 | bf16`。
- `--save-checkpoint`：保存 schema v2 checkpoint。

## v2 三阶段训练

三阶段训练以 `lpt_config` 中的阶段 recipe 为默认配置，CLI 参数只覆盖显式传入的字段。

### text_pretrain

```powershell
python main-pretrain.py --manifest data/manifests/text_pretrain.json --device auto --dtype auto
```

常用覆盖：

```powershell
python main-pretrain.py --batch-size 1 --target-total-epochs 3 --learning-rate 3e-4 --warmup-ratio 0.1 --eval-manifest data/manifests/text_pretrain_eval.json --eval-interval 50
```

### chat_sft

```powershell
python main-sft.py --manifest data/manifests/chat_sft.json --device auto --dtype auto
```

默认会优先从 `artifacts/lpt_v2/text_pretrain` 查找可用 checkpoint 作为初始化；找不到时会显式提示并随机初始化。

### chat_lora

```powershell
python main-LoRA.py --manifest data/manifests/chat_lora.json --base-source text_pretrain --device auto --dtype auto
```

`--base-source` 可选 `text_pretrain` 或 `chat_sft`。LoRA 默认配置来自 `ChatLoRATrainingConfig`，可用 `--lora-rank`、`--lora-alpha`、`--lora-dropout`、`--lora-target-modules` 覆盖。

### 通用训练参数

- `--epochs` / `--target-total-epochs`：训练 epoch 数。
- `--max-steps`：最大训练 batch step；不传则不按 step 截断，按 `epochs` 跑完整数据。
- `--warmup-ratio`：scheduler warmup 比例。
- `--gradient-accumulation-steps`：梯度累积步数。
- `--no-sequence-packing`：关闭 sequence packing。
- `--eval-interval`、`--eval-batch-size`、`--eval-max-batches`：验证配置；不传 `--eval-max-batches` 时跑完整验证集。
- `--save-interval`、`--key-checkpoints`：额外 checkpoint 保存配置。
- `--no-save-optimizer`、`--no-save-scheduler`：关闭续训状态保存。
- `--run-id`：实验运行 ID。
- `--no-tensorboard`：关闭 TensorBoard 输出。

LongRoPE2 训练窗口可用：

```powershell
python main-pretrain.py --longrope2-window-lengths 2048,4096,8192 --longrope2-window-weights 1,1,1 --train-max-sequence-length 8192
```

### Sequence Packing Benchmark

```powershell
python tools/benchmark_lpt_v2_sequence_packing.py --manifest data/manifests/chat_sft.json --manifest-kind chat --checkpoint artifacts/lpt_v2/chat_sft/checkpoints/latest/model.pt --batch-size 4 --warmup-steps 2 --measured-steps 10 --train-max-sequence-length 4096 --device auto --dtype auto --output-json help/LPTv2扩展实验/reports/sequence_packing_benchmark.json --output-md help/LPTv2扩展实验/reports/sequence_packing_benchmark.md
```

该命令对同一批样本分别跑 `sequence_packing=off/on`，输出 token 利用率、active/padded token 吞吐、step 耗时和 CUDA peak memory，用于判断 packing 是否真正降低 padding 浪费和显存峰值。

## v2 基线评测

```powershell
python tools/run_lpt_v2_baselines.py --profiles all --preset lpt_v2_dev_tiny --vocab-size 128 --seq-len 16 --decode-steps 1 --device auto --dtype auto --output-json help/LPTv2扩展实验/reports/lpt_v2_baseline.json --output-md help/LPTv2扩展实验/reports/lpt_v2_baseline.md
```

该命令覆盖：

- `lpt_v2_bootstrap`：Local Attention + SDPA + Dense KV，关闭 RetNetAssist/xLSTM，`moe_num_experts=1`。
- `lpt_v2_sdpa_local`：Local SDPA + Dense KV。
- `lpt_v2_paged_kv`：Local SDPA + Paged KV。
- `lpt_v2_assist`：Paged KV + Shared RetNetAssist Q Adapter。
- `lpt_v2_base`：Assist + SwiGLU-MoE，`moe_num_experts=8`，`moe_top_k=2`。
- `lpt_v2_memory`：Base + xLSTMAssist FFN 输入 adapter。

## Checkpoint schema v2

保存随机初始化 checkpoint：

```powershell
python tools/save_lpt_v2_checkpoint.py --profile lpt_v2_assist --preset lpt_v2_dev_tiny --vocab-size 128 --output artifacts/lpt_v2/dev_tiny/model.pt
```

严格校验 checkpoint：

```powershell
python tools/validate_lpt_v2_checkpoint.py --checkpoint artifacts/lpt_v2/dev_tiny/model.pt --map-location cpu
```

schema v2 loader 会拒绝：

- 非 `checkpoint_format="lpt_v2_checkpoint"`。
- `checkpoint_schema_version` 不等于 `2`。
- `architecture_version` 不等于 `lpt_v2`。
- `model_config_schema_version` 不等于当前 v2 schema。
- runtime metadata 与 `ModelConfig` 中 attention/cache/state schema 不一致。

## Attention / Cache / Assist / MoE 参数

当前主干默认：

- Attention backend：`sdpa`。
- Cache backend：`paged_kv`，`kv_cache_scope="local_real_tokens_only"`。
- RetNetAssist：`retnet_assist_mode="q_adapter"`，只调制 Q，不改 K/V。
- SwiGLU-MoE：`moe_router_dtype="fp32"`，experts 全部为无状态 `SwiGLU`。
- xLSTMMemory：仅在 `lpt_v2_memory` profile 中启用，作为 FFN 输入 adapter，不作为 expert 或 router target。
- xLSTMMemory eval switch：`moe_router_input_mode="ffn_norm_only_eval"` 可在 xLSTM 状态继续更新时绕过 memory adapter 输入。

FA2/FA3 仍只作为 P3 后续性能评估项，不是当前 v2 主线默认后端。
